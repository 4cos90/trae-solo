# 几何冲刺 - 产品需求文档

## 1. 产品概述

一款极简主义风格的敏捷反应游戏，玩家控制一个发光的几何形状在无尽的隧道中冲刺，躲避随机生成的障碍物，收集能量点。游戏节奏紧凑刺激，单局时长1-3分钟，适合随时开一把挑战高分。

**核心体验**：纯粹的反射神经挑战 + 几何美学的视觉享受

---

## 2. 核心功能

### 2.1 游戏机制

| 功能模块 | 描述 |
|---------|------|
| 角色控制 | 玩家控制发光圆形，在三条轨道间左右移动 |
| 障碍物生成 | 随机生成阻挡物（实心方块），需要躲避 |
| 能量收集 | 收集发光的能量球获得加分 |
| 难度递增 | 速度随分数线性增加，保持挑战性 |
| 即时死亡 | 碰到障碍物立即结束，强调失误代价 |

### 2.2 游戏流程

```
开始界面 → 倒计时3秒 → 游戏进行中 → 碰撞结束 → 结算展示 → 返回开始界面
```

### 2.3 数据记录

- 本地存储最高分
- 实时显示当前分数
- 游戏结束时显示本次分数和历史最高

---

## 3. 用户界面设计

### 3.1 视觉风格：现代极简 + 几何美学

**配色方案**：
- 背景：`#0a0a0f`（深邃黑）
- 主色：`#00d4ff`（电光蓝）
- 强调：`#ff006e`（警示粉）
- 能量球：`#ffd700`（金色）
- 文字：`#ffffff`（纯白）

**字体**：
- 标题：Orbitron（科技感几何字体）
- 数字：Space Mono（等宽数字）

**动效**：
- 轨道切换：弹性过渡 150ms
- 障碍物进入：平滑滚动
- 碰撞爆炸：粒子散射动画
- UI元素：淡入淡出

### 3.2 响应式适配

- **桌面端**：键盘 ← → 或 A D 控制
- **移动端**：屏幕左右区域点击控制
- 画布自适应屏幕宽度，最大宽度480px居中
- 保持16:9的竖屏游戏区域比例

---

## 4. 游戏元素规格

| 元素 | 尺寸 | 颜色 | 状态 |
|------|------|------|------|
| 玩家圆形 | 40px | #00d4ff 发光 | 可左右移动 |
| 障碍方块 | 80x80px | #ff006e | 从上向下移动 |
| 能量球 | 30px | #ffd700 闪烁 | 从上向下移动 |

---

## 5. 性能目标

- 60 FPS流畅运行
- 移动端触摸延迟 < 50ms
- 单文件HTML < 50KB
- 无外部依赖（纯Canvas实现）
